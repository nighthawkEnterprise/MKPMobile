# MKP Mobile

MKP Mobile is a React Native / Expo mobile app concept for a nonprofit community organization. It was designed to help members discover events, find nearby groups, view member/community information, and stay engaged through a mobile-first experience.

## Overview

The app was built for MKP, a nonprofit community with a broad membership base. The goal was to create a mobile experience that improves member engagement, event discovery, and participation in local groups.

## Product problem

Community organizations often struggle with engagement after onboarding. Members may want to participate more, but they need a simple way to:

- Find events
- Discover nearby groups
- Look up members or points of contact
- Navigate organization resources
- Re-engage after periods of inactivity

MKP Mobile explores how a lightweight mobile app can reduce that friction.

## Target users

- Existing members who want to participate more actively
- New members who need help finding groups, events, and contacts
- Community organizers who want a better way to surface events and member resources

## Key features

- Login and registration flows
- Bottom-tab navigation
- Drawer navigation
- Home, events, member/group, and community sections
- Event detail screens
- Member/group detail screens
- Native mobile navigation patterns
- Phone/SMS/map-related dependency support for richer mobile interactions

## Tech stack

- React Native
- Expo
- React Navigation
- Drawer navigation
- Material bottom tabs
- Axios
- React Native Maps
- React Native Elements
- React Native Paper
- Native communication libraries for phone/SMS-style interactions

## Product metrics considered

The original project framing focused on:

- App downloads
- Usage by existing members
- Usage by new members
- Member engagement and retention

## Portfolio positioning

It shows experience with:

- React Native development
- Mobile navigation architecture
- Community product design
- Engagement and retention-oriented product thinking

## Running locally

```bash
npm install
npm start
```

Then run with Expo:

```bash
npm run ios
npm run android
npm run web
```
